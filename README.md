# 周末去哪玩 · 上海

> 刷两小时小红书，不如让机器替你选。上海展览 · 市集 · 节庆清单，按剩余天数排序，一键决定这周末去哪。

一个给「周末不知道干嘛」用的静态决策站：把上海正在进行的展览、市集、节庆整理成结构化清单，
支持按 **免费 / 不用预约 / 区域 / 类型** 筛选，还有个 **「帮我选一个」** 的加权随机按钮。

另有一个 **看剧 / 演出页**（`shows.html`）：音乐剧、歌剧、舞剧、话剧、驻演小剧场清单，
按「**本周在演 → 即将开演 → 档期待定 → 已结束**」排序，附**场次时间 / 票价区间 / 时长 / 购票渠道（大麦等）**。
两页顶部互相有导航入口。

零依赖、零构建：`index.html` + 一个数据文件 + 一点原生 JS，GitHub Pages 直接托管。

## 怎么加一个新展

只改 `data/activities.js`，往数组里加一条：

```js
{
  id: 'unique-id',
  name: '展览名',
  type: 'exhibition',        // exhibition | market | event
  venue: '场馆名',
  district: '浦东',           // 用于区域筛选
  address: '详细地址',
  start: '2026-09-25',
  end: '2026-11-15',
  closedDay: '周一闭馆',
  hours: '10:00-21:00',
  price: { free: false, amount: '80 元起', note: '补充说明' },
  booking: {
    required: true,
    level: 'medium',         // none 不用预约 | easy 很简单 | medium 需预约 | hard 需实名抢 | unknown 待开放
    realName: '实名要求说明',
    channel: '「XX」微信小程序',
    steps: ['第一步', '第二步'],
    tip: '提醒，比如快结束了 / 别买黄牛票'
  },
  highlight: '看点一句话',
  tags: ['限时', '免费'],
  rating: 5                   // 1-5，影响「帮我选一个」的权重
}
```

`rating` 越高越容易被随机选中；剩余 ≤10 天、免费的项目也会加权。

## 看剧 / 演出页：怎么加一部新剧

页面是 `shows.html`，数据只改 `data/shows.js`，往 `window.SHOWS` 数组里加一条：

```js
{
  id: 'unique-id',
  name: '剧目名',
  type: 'musical',           // musical 音乐剧 | opera 歌剧 | dance 舞剧/芭蕾 | theatre 话剧 | concert 音乐会 | resident 驻演·小剧场
  venue: '上海文化广场 · 主剧场',
  district: '黄浦',           // 用于区域筛选（黄浦 / 静安 / 浦东）
  address: '黄浦区复兴中路 597 号',
  start: '2026-10-30',        // 首演日；档期未定就留空 ''（会显示「档期待定」）
  end:   '2026-11-15',        // 末场日
  sessions: '14:00 / 19:30',  // 场次时间
  price: { min: 80, max: 1280, text: '80–1280 元', note: '补充说明' },
  duration: '约 150 分钟（含中场）',
  platform: '大麦 / 上海文化广场官网',  // 购票渠道
  language: '法语原版 · 中国首演',
  highlight: '看点一句话',
  tags: ['重磅', '即将开演'],
  rating: 5                   // 1-5，影响「帮我选一部剧」的权重
}
```

排序规则：**在演中 → 即将开演 → 档期待定 → 已结束**（已结束的按末场日倒序，近的在前）。
页面顶部「**本周在演**」自动取本周一~周日有场次的剧目；无排期时提示「最近开演」。
`price.min / max` 用于「票价档」筛选（`有 200 元内票` / `高价位 ≥800`），填 `null` 表示价格待定、归入「不限」。

> ⚠️ 已收录的名剧如《悲惨世界 40 周年音乐会》(2025.11–12)、《巴黎圣母院》(2026.1)、《伊丽莎白》(2026.1)、《基督山伯爵》(2026.7)
> 上海场均已结束，页面上会以「已结束」标记存档；把它们排到末位、默认可见，方便回看档期。

## 数据来源与免责

信息由各主办方官方渠道（上博 / 浦东美术馆 / PSA / 品牌小程序 / 区政府公告等）与公开报道整理，
`verifiedAt` 标注核对日期。**票价、展期、预约规则随时可能变，出行前请以官方最新公告为准。**
