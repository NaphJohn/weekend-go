为什么最推荐「一起去做某事」
① 共同的经历比实物更难忘、更拉近关系；② 没有尺寸 / 色号 / 款式的翻车问题；③ 礼物本身就是一次约会，一举两得；④ 回忆会增值，实物会贬值。
本站立场：重要的日子，优先送「一段一起度过的时间」，实物只是点缀。

💰 大概多少钱（行业通行区间，非某件商品报价）
¥100 以内　心意 / 氛围型
花 + 手写卡、香薰小物、手写信、小零食礼盒。预算低反而更考验用心。
¥100–300　经典入门
品牌爆款口红、护手霜礼盒、乐高小套、钱包、拍立得相纸。性价比最高的「不会错」区间。
¥300–800　主力区间
香水、项链、降噪耳机、机械键盘、智能手表、情侣写真、定制饰品。纪念日 / 生日的主力预算带。
¥800 以上　大件 / 轻奢
包包、高端耳机 / 表、球鞋、摄影器材、周末短途。关系到位再上，注意对方的回礼压力。
🛡️ 送礼避坑清单（比「送什么」更重要）
1. 别送「教做人」的礼物减肥秤、厨具、吸尘器、功效型护肤（美白 / 抗老 / 祛痘）都像在暗示「你需要改」，除非对方明确说过想要。
2. 三大翻车重灾区口红（色号）、香水（香型）、球鞋（款 + 码）错一个就翻车。拿不准就送小样套装 / 礼品卡，或让对方列清单你来买单。
3. 关系不确定别越界戒指、内衣、太贵重、太 personal 的，会给对方压力。分寸感永远比惊喜重要。
4. 别只送实用不送心意包装 + 一张手写卡片很加分，别省；再实用的礼物，配几句话立刻就不同。
5. 记住对方随口说的话「我好想要 X」是最高级情报，远胜你闷头挑半天 —— 平时多留心。
6. 价格别太悬殊送远超对方消费水平的东西会造成回礼压力，关系早期尤其注意。
7. 别送难打理 / 占地方 / 活物大型毛绒、要精心养的植物、宠物，除非确认对方有条件也有意愿。
8. 别送「自我感动」型花了很久很多、但对方用不上的手工 / 摆件，感动的通常只有自己。投其所好 > 自我表达。
9. 价签要处理好撕掉显眼价签，但保留小票 / 退换凭证（悄悄给对方或自己先留着），万一尺寸 / 款不对还能退。
10. 公开场合看场合太私人或太贵重的别在人多时送，容易让对方尴尬；私密场合 + 一件小礼物往往更好。
🎯 按场景送 · 直接抄答案
生日
主力区间 ¥300–800 最稳；提前订餐厅 / 蛋糕；当天一封手写信是杀手锏。别只发个红包。
纪念日
重「回忆」和「仪式」——照片书、相遇地星空图、重游第一次约会的地方。贵在「只有你们懂」，不在贵。
情人节 / 七夕
花 + 一件像样礼物 + 一顿饭三件套；提前订位（这天餐厅爆满）。别临时抱佛脚。
圣诞 / 节日
氛围型最应景——香薰、围巾、礼盒装；可以玩「交换礼物」，约定预算更有趣。重点是氛围，不是价格。
日常小惊喜
不需要节日借口：一束花、一杯她提过的奶茶、一个小物件 + 一句话。效果往往比节日大礼更好。
表白 / 升温
分寸感第一，别一上来就贵重 / 越界；一束花 + 一顿用心的饭 + 一句真诚的话最管用。别用贵重礼物「砸」。
和好 / 道歉
礼物是辅助不是主角：先诚恳沟通，再配一束花 / 一件她提过的小物。别用贵重礼物「堵嘴」，治标不治本。
💞 关系阶段的分寸（比选哪件礼物更要命）
暧昧 / 刚接触预算压低、别越界。安全牌优先（花 + 卡、香薰、一顿饭、一起看展）；别送戒指 / 太贵重的，容易把对方吓退。
稳定交往可以上贴身 / 定制 / 主力区间（项链、香水、耳机、情侣写真）；开始可以送「懂她」的东西，先观察喜好再出手。
长期 / 已婚实用 + 惊喜并重。高频好物（降噪耳机、剃须刀、手表）很实在，但重要的日子仍要有仪式感（纪念日重游、照片书）——别把「过日子」过成「凑合过」。
